Builds / Search Query Generator

How would a real customer type that?

A small tool that takes a merchant or product and generates the many ways real customers would actually search for it — training and test data for commerce search systems.

RoleDesigned & built
StackPlain HTML, CSS, JavaScript
StatusLive — free to use

The problem

A commerce search system is only as good as the queries it was tested and trained against — and real customers don’t search the way product teams write test cases. They type “palm eatery near me”, “paracetamol price”, “order jollof promo”. Writing those variants by hand is slow, and one person’s imagination is a biased sample of how thousands of people actually type.

What I built

Pick a category — restaurant, meal, pharmacy, pharmacy item, shop item — enter a name, and the tool instantly generates query variants around it, weaving in real search intent: near me, price, buy, order, menu, promo. Two modes set the volume: Normal for ordinary phrasings, Aggressive for the messy long tail. No backend, no sign-up — everything runs in the browser, output ready to copy into a test suite or a training set.
