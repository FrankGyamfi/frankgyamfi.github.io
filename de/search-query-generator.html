Projekte / Search Query Generator

Wie würde ein echter Kunde das eintippen?

Ein kleines Tool, das aus einem Händler oder Produkt die vielen Arten erzeugt, wie echte Kunden tatsächlich danach suchen würden — Trainings- und Testdaten für Suchsysteme im E-Commerce.

RolleEntworfen & gebaut
TechnikReines HTML, CSS, JavaScript
StatusLive — kostenlos nutzbar

Das Problem

Ein Suchsystem im E-Commerce ist nur so gut wie die Suchanfragen, mit denen es getestet und trainiert wurde — und echte Kunden suchen nicht so, wie Produktteams Testfälle schreiben. Sie tippen „palm eatery near me“, „paracetamol price“, „order jollof promo“. Solche Varianten von Hand zu schreiben ist langsam, und die Vorstellungskraft einer einzelnen Person ist eine verzerrte Stichprobe dafür, wie Tausende Menschen tatsächlich tippen.

Was ich gebaut habe

Kategorie wählen — Restaurant, Gericht, Apotheke, Apothekenartikel, Ladenartikel —, einen Namen eingeben, und das Tool erzeugt sofort Suchvarianten dazu und verknüpft sie mit echter Suchabsicht: near me, price, buy, order, menu, promo. Zwei Modi bestimmen die Menge: Normal für übliche Formulierungen, Aggressive für den unordentlichen Long Tail. Kein Backend, keine Anmeldung — alles läuft im Browser, die Ausgabe ist bereit zum Kopieren in eine Testsuite oder einen Trainingsdatensatz.
